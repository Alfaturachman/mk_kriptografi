Algoritma & metode sistem

Arsitektur proteksi citra medis DICOM terintegrasi dalam empat pilar: Enkripsi Kriptografis AES-256-CBC, Reversible Watermarking Multi-Round (PEE-HS), Partisi Spasial ROI/RONI, dan Deteksi serta Lokalisasi Manipulasi Spasial Grid 16×16.

1. Enkripsi Kriptografis AES-256-CBC

Kerahasiaan data pasien: payload tanda tangan biner dienkripsi sebelum disisipkan.

  • Derivasi kunci kuat menggunakan PBKDF2-HMAC-SHA256 (200.000 iterasi) dengan Salt acak 16 byte.
  • Vektor Inisialisasi (IV) acak 16 byte memastikan ciphertext unik meski data atau kata kunci serupa.
  • Mengamankan struktur payload biner: Magic header RPEE01 (80b) + Digest SHA-256 metadata (256b) + 594 Hash Blok Spasial (9.504b) → 10.144 bit ciphertext dengan padding PKCS#7.
  • Proteksi berkas tingkat kontainer (.krip) menggunakan format AES1 | salt | iv | ciphertext.
key = PBKDF2_HMAC_SHA256(passphrase, salt, iterations=200000, dklen=32)
cipher = AES_CBC(key, iv).encrypt(pad_pkcs7(payload_binary))
file_krip = b"AES1" + salt + iv + cipher

2. Reversible Watermarking (PEE-HS Multi-Round)

Jaminan Reversibilitas 100%: citra diagnostik dapat dipulihkan sempurna secara eksak biner.

  • Skema Checkerboard: Piksel dipartisi selang-seling menjadi piksel referensi (tetap) dan piksel target (disisipi).
  • Prediktor MED (Median Edge Detector): Menghitung nilai prediksi ê berdasarkan tetangga spasial; galat prediksi dihitung sebagai e = x - ê.
  • Perluasan Galat (Error Expansion): Bit rahasia disisipkan pada titik puncak histogram (peak e0) via e' = 2e + b.
  • Pergeseran Histogram (Histogram Shifting): Nilai galat di luar puncak digeser e' = e ± 1 guna mencegah benturan bin (bin collision).
  • Pemulihan Integer Eksak: Penerima mengekstrak bit via b = e' mod 2 dan memulihkan galat via integer division e = ⌊e'/2⌋ tanpa kesalahan pembulatan desimal.
  • Multi-Round Adaptif: Dijalankan hingga 16 round dinamis guna menampung payload besar (10.144 bit) dengan distorsi tak kasat mata (PSNR rata-rata 86,35 dB, SSIM 0,999995).
# Penyisipan (Forward):
e = x - x_pred
if e == peak:   e_mod = 2 * e + b
elif e > peak:  e_mod = e + 1
x_watermarked = x_pred + e_mod

# Pemulihan (Inverse):
e_mod = x_watermarked - x_pred
b = e_mod % 2
e_orig = e_mod // 2
x_restored = x_pred + e_orig   # 100% IDENTIK!

3. Partisi Spasial: ROI Diagnostik & Strip RONI

Segmentasi fungsional untuk mengisolasi parameter kontrol dari wilayah anatomi medis.

  • Wilayah Diagnostik / ROI (Baris 0 s.d. 431): Matriks anatomi otak 432×364 piksel (157.248 piksel) yang diproteksi secara eksak murni (PSNR = ∞, BER = 0, SSIM = 1,0).
  • Strip Sintetis / RONI (16 Baris Terbawah): Wilayah 16×364 piksel di luar organ pasien yang difungsikan sebagai media penyimpanan parameter side-channel (e0, arah geser, jumlah bit per round) dalam format JSON terkompresi.
  • Seluruh informasi dekompresi tertanam secara mandiri (*in-band*), tidak memerlukan berkas sidecar eksternal yang rentan terpisah.
roi_pixels  = dicom_pixels[0:432, :]   # Wilayah diagnostik otak (Bit-Exact)
roni_strip  = dicom_pixels[432:448, :] # Strip parameter kontrol (Side-channel LSB)

4. Deteksi Integritas & Lokalisasi Manipulasi (Grid 16×16)

Verifikasi bebas referensi: deteksi manipulasi lokal hingga skala blok 16×16 piksel.

  • Invariansi Bit Stabil: Setiap piksel digeser 1 bit ke kanan (pixel >> 1) agar representasi hash blok independen dari manipulasi bit rendah.
  • Hash Spasial Blok: ROI dibagi menjadi 594 blok berukuran 16×16 piksel (27 baris × 22 kolom). Masing-masing blok di-hash dengan SHA-256 terpotong 16 bit (total 9.504 bit).
  • Digest Metadata DICOM: Atribut klinis penting (PatientID, StudyDate, Modality, SeriesInstanceUID) di-hash penuh dengan SHA-256 (32 byte / 256 bit).
  • Lokalisasi Tamper: Bila terjadi serangan/modifikasi lokal, blok yang tidak cocok langsung ditandai dengan masker merah pada layar radiologi.
# Hitung ulang hash blok dari citra hasil pemulihan:
block_hash = SHA256(block_pixels >> 1)[:2]   # 16-bit
if block_hash != stored_block_hash:
    tamper_mask[block_coords] = 255          # Tandai blok merah 16x16!
