Algoritma & metode

Empat metode inti bekerja sebagai satu kesatuan: gembok (AES), stempel pembeda (LSB watermarking), tanda tangan (SHA-256), dan sekuriti pamungkas yang mendeteksi manipulasi (tamper detection per blok).

AES-256-CBC

Kerahasiaan: seluruh byte berkas dienkripsi dengan kunci turunan PBKDF2.

  • Kunci di-derive dari password melalui PBKDF2-HMAC-SHA256 (200.000 iterasi) + salt acak 16 byte.
  • IV acak 16 byte per enkripsi memastikan hasil berbeda tiap proses walau isi sama.
  • Ciphertext disimpan dengan format AES1 | salt | iv | data.
key = PBKDF2(password, salt, len=32)
enc = AES_CBC_encrypt(pad(plaintext), key, iv)
file = "AES1" + salt + iv + enc

LSB Watermarking

Penyisipan stempel pada bit paling tidak signifikan bernilai tak terlihat.

  • Setiap blok 8x8 membawa 16 bit hash 7-bit-tertinggi miliknya sendiri pada LSB kanal merah.
  • Grayscale (DICOM) menempatkan metadata di 8 baris terbawah agar tak bertabrakan dengan stempel blok.
  • Perubahan maksimal 1 dari 65535 pada citra 16-bit, atau 1 dari 255 pada 8-bit: tak mengganggu diagnosis.
lsb = pixels & ~1        # bersihkan bit terakhir
pixels = lsb | bit       # sisipkan 1 bit data

SHA-256 Signature

Tanda tangan integritas metadata pasien disisipkan ke LSB.

  • Metadata (PatientID, PatientName, StudyDate, Modality, UID, dll.) digabung jadi string tunggal.
  • Hash SHA-256 (32 byte) dari string itu disisipkan ke area metadata citra.
  • Saat verifikasi, hash dihitung ulang dari metadata saat ini lalu dibandingkan.
digest = SHA256(metadata)   # 32 byte
embed_lsb(image, digest)
...

Tamper Detection & Lokalisasi

Verifikasi bebas referensi: tak perlu citra asli untuk menemukan area yang diubah.

  • Hitung ulang hash tiap blok dari 7 bit tertinggi piksel yang ada sekarang.
  • Bandingkan dengan hash yang terekstrak dari LSB blok.
  • Blok yang tidak cocok ditandai penuh 8x8 — piksel yang dimanipulasi terlokalisasi presisi.
current = hash7(pixels)          # konten saat ini
stored  = read_lsb(pixels)        # stempel blok
mask    = i where current[i] != stored[i]
